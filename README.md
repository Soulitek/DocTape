# יומן גיבוי קלטות אופסייט

אפליקציית ווב מקומית לניהול מעקב אחר מחזור החיים של קלטות גיבוי LTO עבור MSP.

## תכונות

- ✅ ניהול מלא של רשומות (CRUD) - הוספה, עריכה, מחיקה
- ✅ **סל מיחזור** — מחיקה רכה עם שחזור מלא
- ✅ **שמירה לקובץ JSON** על הדיסק (File System Access API)
- ✅ חיפוש וסינון בזמן אמת
- ✅ מיון לפי עמודות
- ✅ ייצוא ל-CSV ול-JSON
- ✅ ייבוא מ-JSON
- ✅ ממשק בעברית עם תמיכה ב-RTL
- ✅ תמיכה במובייל (Responsive)
- ✅ עובד ללא חיבור לאינטרנט
- 🔒 **פרטיות מלאה - נתונים לא נשלחים לענן**

## שימוש

1. פתח את הקובץ `tape-log.html` בדפדפן (כפול קליק)
2. בפתיחה הראשונה, בחר קובץ JSON לשמירת הנתונים
3. האפליקציה תשמור לקובץ אוטומטית מכאן ואילך

> **דפדפן מומלץ:** Chrome או Edge (לתמיכה מלאה ב-File System Access API).  
> Firefox ישתמש ב-LocalStorage כגיבוי.

## שדות הטופס

### שדות חובה:
- **ברקוד קלטת** - מזהה ייחודי של הקלטת
- **תאריך גיבוי אחרון** - תאריך הגיבוי האחרון

### שדות נוספים:
- **מערכות מגובות** - רשימת המערכות שהוגנו
- **תאריך ייצוא** - תאריך הייצוא לאופסייט
- **שעת ייצוא** - שעת הייצוא
- **מייצא** - שם האחראי על הייצוא (חובה אם תאריך ייצוא מוזן)
- **יעד אופסייט** - מיקום האחסון (חובה אם תאריך ייצוא מוזן)
- **תאריך החזרה** - תאריך החזרה מהאופסייט
- **הערות** - הערות נוספות

## 🔒 פרטיות ושמירת נתונים

- הנתונים נשמרים **רק על המחשב שלך** — בקובץ JSON שתבחר
- LocalStorage משמש כגיבוי אוטומטי מקביל
- **לא נשלח לענן**, לא נאסף, לא משותף

### שמירה לקובץ (File System Access API)

בפתיחה הראשונה תוצג חלונית בחירה:

| אפשרות | תיאור |
|---|---|
| **פתח קובץ קיים** | טעינת נתונים מקובץ JSON קיים |
| **צור קובץ חדש** | בחירת מיקום ושם לקובץ חדש |
| **המשך ללא קובץ** | שימוש ב-LocalStorage בלבד |

לאחר הבחירה, כל שמירה כותבת לקובץ אוטומטית.  
לשינוי קובץ: **ייצא/ייבא ← שנה קובץ נתונים**

### סל מיחזור

לחיצה על 🗑️ בשורה **אינה מוחקת לצמיתות** — הרשומה עוברת לסל המיחזור.

| פעולה | תיאור |
|---|---|
| **♻️ שחזר** | מחזיר רשומה לטבלה הראשית |
| **🗑️ מחק לצמיתות** | מחיקה בלתי הפיכה של רשומה בודדת |
| **מחק הכל לצמיתות** | ריקון מלא של סל המיחזור |

מספר הרשומות בסל מוצג כתג אדום על כפתור "סל מיחזור".
